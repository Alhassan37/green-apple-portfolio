لوحة تحكم الموقع

عدّل الإيفنتات والتجارب وآراء العملاء والمركبات ونصوص الموقع، واضغط «احفظ وانشر» — التعديل يظهر على الموقع خلال دقيقة.

إزاي أعمل مفتاح الدخول؟ (مرة واحدة بس)
  1. افتح صفحة إنشاء مفتاح على GitHub وانت داخل على حسابك.
  2. Token name: اكتب Green Apple Admin — وExpiration: اختار مدة (مثلًا سنة).
  3. Repository access: اختار Only select repositories وبعدها green-apple-portfolio.
  4. Permissions ← Repository permissions ← Contents: اختار Read and write.
  5. اضغط Generate token، انسخ المفتاح والصقه هنا.

المفتاح بيتحفظ على جهازك بس، ومحدش يقدر يعدّل الموقع من غيره.
