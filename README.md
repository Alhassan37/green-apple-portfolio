# Green Apple — جرين ابل للاستثمار الزراعي

موقع بورتفوليو تفاعلي لجرين ابل: 6 وكالات عالمية و60 مركب، بأنيميشن وموسيقى متولّدة في المتصفح.

## المحتوى
- **المدخل:** صورة حقيقية لبوابة خشب مقوّسة، وعليها لوحة حجر محفور فيها GREEN APPLE واللوجو، وعلى الجنبين منتج من كل وكالة. بتضغط على البوابة (أو تعمل سكرول)، فالبابين بيتفتحوا على فيديو حقيقي لمزرعة برتقال، والكاميرا بتمشي في الممر وتطلع فوق المزرعة، وبعدها الموقع يفتح. صورة الباب وفيديو المزرعة من Pexels (رخصة مجانية للاستخدام التجاري).
- **الماوس:** على شكل ورقة اللوجو.
- **الوكالات:** JISA · MBFi · Introlab · Kheme · Fertinagro · Newnutri، في كاروسيل بيتسحب يمين وشمال (ماوس، تاتش، تراك باد، أسهم الكيبورد)، ولكل وكالة بروفايل بمركباتها.
- **وضع فاتح وداكن:** زرار في الشريط العلوي، والموقع بيفتكر اختيار الزائر.
- **مستكشف المركبات:** بحث وفلترة بالوكالة وبالاحتياج (إجهاد، جذور، تزهير، تحجيم…).
- **صفحة لكل مركب:** صورة العبوة والتركيبة وزرار استفسار على واتساب.
- **من الأرض:** 4 تابات — الإيفنتات بتواريخها (جنوب أفريقيا، صحارى، الأقصر)، النتايج حسب المحصول، النتايج حسب المركب، وآراء العملاء بالفيديو. كل إيفنت ومحصول ومركب ليه صفحة بلينك مباشر (`#event-…`، `#crop-…`، `#product-…`).
- **فريقنا:** فيديو «في كل مكان» متركّب من لقطات الفريق بالترتيب، وجنبه كلام الفيديو (اضغط على أي جملة تروح لها)، وصورة الفريق.
- **تطبيق:** يتنزل على الموبايل من المتصفح (PWA).
- **الموسيقى:** متولّدة بـ Web Audio API (مفيش ملفات صوت). الموقع بيفتح من غير صوت، والزائر يقدر يشغّلها من زرار الصوت، والموقع بيفتكر اختياره. وبتسكت لوحدها لما فيديو يشتغل.

## التشغيل
موقع ثابت (HTML/CSS/JS) من غير build. افتح `index.html` في المتصفح، أو شغّل سيرفر محلي:

```bash
python -m http.server 5517
```

## الملفات
| المسار | المحتوى |
|---|---|
| `index.html` | هيكل الصفحة |
| `css/style.css` | التصميم |
| `js/app.js` | الأنيميشن والتفاعل |
| `js/gate.js` | مشهد بوابة المزرعة في أول الموقع |
| `assets/gate/` | صورة الباب وفيديو مزرعة البرتقال (Pexels) |
| `js/music.js` | الموسيقى والمؤثرات الصوتية |
| `data/*.js` | كل المحتوى (نصوص الموقع، المركبات، الوكالات، الإيفنتات، التجارب، آراء العملاء) |
| `js/preview.js` | بيملأ النصوص من `data/site.js` |
| `js/fieldui.js` | تابات «من الأرض» وصفحات التفاصيل وفيديو الفريق |
| `assets/products/` | صور العبوات (WebP) |
| `assets/field/` | صور الإيفنتات والتجارب وفيديوهات آراء العملاء |
| `assets/team/` | فيديو وصور الفريق |

المكتبات: GSAP 3.12.5 (ScrollTrigger, Flip) و Lenis 1.1.13 من CDN.
