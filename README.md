# Green Apple — جرين ابل للاستثمار الزراعي

موقع بورتفوليو تفاعلي لجرين ابل: 6 وكالات عالمية و60 مركب، بأنيميشن وموسيقى متولّدة في المتصفح.

## المحتوى
- **الوكالات:** JISA · MBFi · Introlab · Kheme · Fertinagro · Newnutri، ولكل وكالة بروفايل بمركباتها.
- **مستكشف المركبات:** بحث وفلترة بالوكالة وبالاحتياج (إجهاد، جذور، تزهير، تحجيم…).
- **صفحة لكل مركب:** صورة العبوة والتركيبة وزرار استفسار على واتساب.
- **الموسيقى:** متولّدة بـ Web Audio API (مفيش ملفات صوت)، وبتشتغل بعد ما الزائر يدوس "ادخل التجربة بالصوت".

## التشغيل
موقع ثابت (HTML/CSS/JS) من غير build. افتح `index.html` في المتصفح، أو شغّل سيرفر محلي:

```bash
python -m http.server 5517
```

## الملفات
| المسار | المحتوى |
|---|---|
| `index.html` | هيكل الصفحة |
| `css/style.css` | التصميم |
| `js/app.js` | الأنيميشن والتفاعل |
| `js/music.js` | الموسيقى والمؤثرات الصوتية |
| `js/products.js` | بيانات الـ60 مركب |
| `js/agencies.js` | بيانات الوكالات والاحتياجات |
| `assets/products/` | صور العبوات (WebP) |

المكتبات: GSAP 3.12.5 (ScrollTrigger, Flip) و Lenis 1.1.13 من CDN.
